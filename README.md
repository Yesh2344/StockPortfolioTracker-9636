## Overview

StockPortfolioTracker is a lightweight, production‑ready web application that lets users monitor a personal stock portfolio in real time. It combines a **Flask** backend (Python) that fetches live data from the Alpha Vantage API with a modern, responsive **HTML/CSS/JavaScript** frontend.

Features:

- Real‑time price lookup for any ticker.
- Portfolio persistence via browser `localStorage`.
- Automatic refresh every 5 minutes.
- Comprehensive error handling and logging.
- Fully typed Python code and documented JavaScript.
